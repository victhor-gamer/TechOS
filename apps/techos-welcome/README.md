# TechOS Welcome

The official welcome application for TechOS.

## Overview

TechOS Welcome is planned to be the first application users interact with after installing TechOS.

Its purpose is to introduce users to the system and provide quick access to useful features.

## Planned Features

- Welcome screen
- System introduction
- Initial setup guidance
- Hardware and system information
- Documentation shortcuts
- Useful system links
- Community links

## Design

The application will follow the official TechOS visual identity:

- Frutiger Aero inspiration
- Blue color palette
- Glass-inspired interface
- Clean and modern layout

## Compatibility

- Operating system: TechOS
- Base: Debian
- Architecture: AMD64 (x86_64)
- Desktop environment: Cinnamon
