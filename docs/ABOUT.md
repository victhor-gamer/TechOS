Sobre o TechOS

TechOS — O futuro que o passado imaginou, continua.

O TechOS é um projeto independente de distribuição Linux baseada em Debian.

Objetivos

- Criar uma experiência desktop própria.
- Utilizar Cinnamon como ambiente gráfico.
- Desenvolver ferramentas exclusivas.
- Construir uma identidade visual Frutiger Aero.
- Oferecer uma distribuição acessível e estável.
