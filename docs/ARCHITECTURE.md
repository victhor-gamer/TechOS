TechOS Architecture

Supported Architectures

AMD64 (x86_64)

- Status: Primary target architecture
- Processor architecture: x86_64
- Compatible with 64-bit AMD and Intel processors
- Base system: Debian AMD64
- Package format: DEB
- Package manager: APT
