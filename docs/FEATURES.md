TechOS Features

Official feature list of the TechOS operating system.

1. Desktop Environment

- Cinnamon desktop environment
- Muffin window manager
- Frutiger Aero visual identity
- Custom themes and icons
- Custom wallpapers
- Personalized login screen

2. System Tools

TechOS Welcome

- First-start welcome screen
- Initial system configuration
- Useful links and documentation

TechOS Center

- Centralized system settings
- Desktop customization
- System information

TechOS Store

- Application discovery
- Software installation
- Application management

TechOS Update

- System update management
- Update notifications
- Package update information

TechOS Info

- Hardware information
- System version
- Architecture information
- Resource monitoring

3. System Compatibility

- AMD64 (x86_64) support
- Debian package compatibility
- APT package management
- DEB package format

4. Visual Identity

- Blue technology-inspired design
- Glass-like visual elements
- Frutiger Aero-inspired interface
- Consistent icons and interface elements

5. Security and Maintenance

- Debian security updates
- System package management
- Basic system maintenance tools

6. Future Features

- Official TechOS package repository
- Custom installer
- Additional supported architectures
- More original system applications
