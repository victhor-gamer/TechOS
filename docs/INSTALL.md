# TechOS Installation

## Current availability

TechOS 1.0 Unstable is under development. An official bootable ISO and installer are not available yet.

Do not follow generic installation steps as if a release image already existed.

## Planned target

- Architecture: AMD64 (x86_64)
- Base: Debian
- Desktop: Cinnamon

## Planned installation process

1. Download an official TechOS ISO when one is published.
2. Verify its checksum and signature, when provided.
3. Write the image to suitable installation media.
4. Boot the target computer.
5. Follow the installer.
6. Reboot and verify the installation.

## Testing

Until an official installer exists, development should be tested in a virtual machine. Back up important data before testing experimental operating-system images.
