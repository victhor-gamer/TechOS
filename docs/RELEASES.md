# TechOS Releases

This document tracks TechOS release channels and published versions.

## Version format

TechOS uses `MAJOR.MINOR.PATCH` version numbers.

## Release channels

- **Unstable:** experimental development builds.
- **Testing:** builds undergoing validation.
- **Stable:** releases approved for general use.

## Planned release

### TechOS 1.0 Unstable

Status: In development.

Planned target:
- Debian-based system
- AMD64 (x86_64)
- Cinnamon desktop
- TechOS branding and applications
- Bootable installation image

## Release checklist

- [ ] Build completes successfully.
- [ ] Boot tested in a virtual machine.
- [ ] Installation tested.
- [ ] Package dependencies checked.
- [ ] Known issues documented.
- [ ] Checksums published.
