# TechOS Security Policy

## Project status

TechOS is experimental software in early development. It is not currently recommended for systems that require production-grade security assurances.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue.

Use GitHub's private vulnerability reporting feature if it is enabled for this repository. If it is unavailable, contact the project maintainer privately through a verified project contact channel.

Do not include passwords, private keys, personal data, or unrelated sensitive information in reports.

## Security goals

The project intends to:

- Prefer trusted Debian repositories and signed packages.
- Keep dependencies maintained.
- Minimize unnecessary privileges.
- Review changes that affect installation or system services.
- Test packages before publication.

## Supported versions

| Version | Status |
|---|---|
| 1.0 Unstable | Experimental; no security support guarantee |

A formal response-time commitment has not yet been established.
